# V1 — P08

V1 is exactly the research's Phase 1 scope (`16-final/RECOMMENDED_ARCHITECTURE.md`) — no more, no less.

## In scope

- File-First ingestion, extending `product-import.tsx` after upgrading the `xlsx` dependency off the vulnerable `0.18.5` version.
- Minimal provenance extension: `source`/`sourceRecordedAt` generalized to variant/price/media scope; per-batch import log (import-batch + import-record tables, per `06-data/DATA_REQUIREMENTS.md`).
- Exact-match-only identity resolution (`sku`, `barcode`, normalized-title+attributes); unresolved rows held in a persisted, reviewable queue — never guessed, never silently discarded.
- Schema-mapping AI-assist (residual columns only, always human-confirmed before first use).
- Attribute-normalization AI-assist (per-brand-scoped lookup table, AI only on miss, self-improving).
- Suggest-only SKU candidate queue for held rows (fuzzy/AI-ranked, human confirms/rejects, never auto-writes).
- Anomaly-explanation AI (plain-language explanation after a deterministic rule fires; rules are the detector).
- Dry-run diff + explicit brand approval gate before any write.
- Per-row/per-batch failure isolation, retry without duplicate writes.
- **F10 access-control fix** — independent of the above, ships immediately regardless of the rest of V1's timeline (BRule-11).

## Required failure scenarios (all must be exercised, per `16-final/POC_PLAN.md`, reused verbatim)

Malformed file; missing required field; ambiguous column; unknown SKU; duplicate SKU; schema drift; invalid stock value; missing/misassociated image; partial failure; retry of a partially-failed batch.

## Explicitly excluded from V1

Orders, fulfillment, returns, any OMS/ERP-replacement functionality (never in scope for the whole program); generalized API-First beyond the existing Unicommerce connector; Scheduled-File; the full confidence-tier auto-apply spine; SKU-matching AI auto-apply; the `brand_external_identifiers` multi-source table; webhook/SFTP/iPaaS/GS1 infrastructure; any reconciliation dashboard or audit-sampling surface; multi-warehouse/location inventory.

## Success bar

See `09-validation/SUCCESS_METRICS.md` — V1 succeeds by closing F4 and F7 for the File-First path, not by brand-tier coverage breadth.
