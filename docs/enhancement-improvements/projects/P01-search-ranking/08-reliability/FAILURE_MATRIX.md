## Cross-cutting observation

Every failure mode that is *already handled well* (dependency failure, partial success) shares the same shape: independent try/catch per branch, silent console-only logging, no structured audit trail, no monitoring/alerting. This Epic's fixes (REN-146) add a *time bound* to entering these already-correct fallback paths — they do not need to redesign the fallback handling itself. The genuinely unhandled gaps (timeout, stale data, result-count race) are exactly the three issues (REN-146, REN-148, REN-155) that name themselves after these gaps.
