# V3 — P01

## No V3 is defined

There is no evidenced basis for a third horizon of work on this Epic. The only candidate that could ever reach this far out — Option C in `07-feasibility/ALTERNATIVES.md` (Renivet owning search/ranking end-to-end via pgvector, replacing the external microservice) — is explicitly REJECTED for now and only "POC-worthy" pending a strategic decision that has not been made and that this documentation pass does not make.

**Trigger that would create a real V3, if it ever occurs:** a product owner strategically decides Renivet should own its search/ranking stack (for cost, control, or capability reasons), *and* REN-148/V2's data shows the external dependency is a recurring, unresolvable source of drift or reliability risk. Absent both of those, writing a V3 here would be inventing future scope with no evidence — exactly what this program's anti-overengineering discipline warns against (see `11-critique/ANTI_OVERENGINEERING_REVIEW.md`).
