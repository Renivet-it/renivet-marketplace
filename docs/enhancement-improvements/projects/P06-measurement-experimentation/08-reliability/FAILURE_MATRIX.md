## The most dangerous failure mode

The currency-unit defect (REN-145a) is explicitly the most dangerous class of failure here: **silent data corruption, not a crash.** Every other failure mode in this table either produces a visible gap (missing events, zero counts) that an attentive analyst would eventually question, or a documented/explainable discrepancy. The currency defect produces *plausible-looking wrong numbers* — a corrupted AOV/ROAS input that could pass a casual sanity check, which is why it required source-code-level investigation (not just dashboard comparison) to confirm.
